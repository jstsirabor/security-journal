### What I tried
- I ran `find / -user bandit7 -group bandit6 -size 33c >/dev/null`. However this send the output i want into the void and keeps the error. To solve this we use the command `find / -user bandit7 -group bandit6 -size 33c 2>/dev/null`. This happened because the flood of "Permission denied" messages go to standard error, which you see. You want the opposite: suppress the errors, keep the output. So you need `2>/dev/null` (redirect stderr).
