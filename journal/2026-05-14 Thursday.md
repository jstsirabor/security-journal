### What I learned
- nmap is used to probe a system to see whether it is connected to the network and finds out what ports are open. From the open ports discovered, we can get.+ what services are running on the target. The syntax is `nmap <type of scan><target IP><optionally, target port>`
- The most reliable nmap scan is the TCP scan. For example, `nmap -sT 192.168.181.1 -p 3306`. The port is optional.
- MySQL uses port 3306 by default and it is valuable as it contains credit card numbers and personally identifiable information (PII) that is very valuable on the black market.
- In nmp, `-A` is used to enable OS and version detection, script scanning and traceroute while `-T4` is for faster execution and then the hostname. e.g. `nmap -A -T4 scanme.nmap.org`
- Apart from Grepable `-oG` format, there are multiple other commands like normal, human readable format `-oN`, XML format for parsing with scripts and tools `-oX` and all three formats simultaneously `-oA`
