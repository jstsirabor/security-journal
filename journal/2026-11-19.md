### What I learned
- In Python, Strings come with built-in tools called methods which can be accessed with a dot ( . )
- The most important important method for security engineers isthe `.split()` method because when reading a log file which has lines as strings, we can separate the string into list of individual words so that we can analyze them.
	- For example, Line = "Failed password for admin". line.split() cuts the line at every space.
- `.upper()` makes  the whole string uppercase and `.lower()` makes the whole string lowercase. This is useful when logs are messy and  what we want to catch has various variation like failed, Failed and FAILED
- `.replace()` changes a specific part of a string. THis is useful when we wanna hide sensitive informataion (like passwords or API keys). For example, `.replace("old_text", "new_text")`
- The `in` operator is used to check if a string contains something. If yes, it returns True and if not,it returns False.
	- For example, ``if "vulnerable" in response: print("Target is compromised!").
- Python can do all standard maths: -, +, * and /(regular division). It can also do integer division and modulo which are useful in computer science and cryptography.
	- Integer division has the sign //. It divides and throws away the remainder. e.g 10//3 is 3
	- Modulo has the sign %. It divides and keeps only the remainder. e.g 10%3 is 1.
	- Modulo is the backbone of cryptography (like RSA and Diffie-Hellman). It is used in binary math and hashing algorithm.
- When you are calculating how many packets fit into a network buffer, or how many blocks are in a file, you use `//` (integer division). If you use `/`, you might get a decimal that causes your script to crash later.
