Full pipeline: `awk '/Failed/ {for(i=1;i<=NF;i++) if($i=="from") print $(i+1)}' file | sort | uniq -c | sort -nr`."_

**Old pipeline (using `cut`):**
`grep "Failed" auth.log | cut -d " " -f 10 | sort | uniq -c | sort -nr`
**New pipeline (using `awk` for robust extraction):**
`grep "Failed" auth.log | awk '{for(i=1;i<=NF;i++) if($i=="from") print $(i+1)}' | sort | uniq -c | sort -nr`
Or even better — do the filtering inside `awk` itself:
`awk '/Failed/ {for(i=1;i<=NF;i++) if($i=="from") print $(i+1)}' auth.log | sort | uniq -c | sort -nr`
**Why this is powerful:** It handles the "invalid user" line correctly and still produces a ranked list of IPs.

The real advantage is: **doing filtering inside `awk` is one process instead of two, and lets you combine multiple conditions in one place.** But the deeper point is that `awk` can filter **and** extract **and** format — all in one command. `grep` can only filter.
- NF = number of fields (a number)
- $NF = content of the last field
- NR - the record number or current line number
- $NR - doesn't exist / meaningless

### What I learned
- `awk` is a **text processing language**. It's not just a command — it's a full programming language designed for scanning and manipulating text. You use it to:
	- Extract specific fields from each line.
	- Filter lines based on conditions.
	- Do calculations on numbers.
	- Format output.
- For log analysis, it's more powerful than `cut` because it handles **variable field counts**, does **pattern matching**, and lets you **print fields by name** (not just position).
- The basic structure is `awk 'pattern { action }' file`
	- **pattern** — optional. If omitted, action runs on every line.
	- **action** — what to do (usually `print`).
	- **file** — the file to process.
- `awk` automatically splits each line into fields based on whitespace (spaces or tabs).
	- `$0` -> The entire line
	- `$1` -> First field
	- `$2` -> Second field
	- ... -> ...
	- `$NF` -> Last field (NF = number of fields)
	- `$(NF-1)` -> Second-to-last field
- `awk '/Failed/ {print $10}' fake_auth.log` would print on;y the ip address with failed entry. `'/Failed/'` matches "Failed" — case-sensitive. For case-insensitive, use `tolower($0) ~ /failed/`.
- For files like `/etc/passwd` that are colon-separated, we can use `-F:`. For example: `awk -F: '{print $1}' /etc/passwd` which would print the first field of every line which is the username. Another example would be `awk -F: '{print $1, $3}' /etc/passwd | head -5` which would print the first 5 usernames and their UIDs
- `cut` just extracts fixed positions. `awk` is a full programming language.
- Built-in variables for `awk`

| Variable | Meaning                                 |
| -------- | --------------------------------------- |
| `NR`     | Current **line number** (record number) |
| `NF`     | Number of fields in the current line    |
| `$0`     | The entire current line                 |
| `FS`     | Field separator (default: whitespace)   |
| `OFS`    | Output field separator (default: space) |
- `awk 'tolower($0) ~ /failed/ {print NR, $10}' fake_auth.log` -> prints the line nmber of the ip for every line containing failed or Failed
- You can filter with conditions inside `awk`:
	- `awk '$3 > 100 {print $1}' numbers.txt`: This prints field 1 for lines where field 3 is greater than 100.
	- `awk '/Failed/ && $10 ~ /^192\./ {print $10}' fake_auth.log`: This prints IPs that start with `192.` on lines containing "Failed".
- `~` simply means contains
- `awk` can sum, average, count. 
	- **To Sum a column:**
		`awk '{sum += $2} END {print sum}' numbers.txt`
		- `{sum += $2}` — for each line, add field 2 to a running total.
		- `END {print sum}` — after all lines, print the total.
	- **Count lines:**
		`awk 'END {print NR}' numbers.txt`
		- `NR` is the number of lines processed.
- `awk` — Output Formatting: You can control how `awk` formats output using `printf` or by setting `OFS` (Output Field Separator).
	- Using `printf`
		`awk '/Failed/ {printf "IP: %s\n", $10}' fake_auth.log`
		- `%s` — placeholder for a string.
		- `\n` — newline.
		IP: 192.168.1.100
		IP: 10.0.0.5
		**Why a security person cares:** Clean, readable output. You can format reports, label fields, and align columns.
	- Using `OFS`: 
		You can change the default output separator from a space to something else:
		`awk 'BEGIN {OFS=":"} {print $1, $2}' file`
		This prints fields 1 and 2 separated by a colon instead of a space.

### Commands/code worth remembering
```code
awk '/Failed/ {for(i=1;i<=NF;i++) if($i=="from") print $(i+1)}' file

**Breaking it down:**

- `/Failed/` — only process lines containing "Failed".
    
- `for(i=1;i<=NF;i++)` — loop through every field (1 to NF).
    
- `if($i=="from")` — when you find a field equal to "from".
    
- `print $(i+1)` — print the **next** field (the IP).
    

**Why it works:** No matter how many words come before "from", the IP is always **the field immediately after "from"**. **it finds the field labeled `from` and then takes the next field, regardless of its position.** So even if extra words shift field numbers, the IP is always the field right after `from`. That's why it's robust.
```
