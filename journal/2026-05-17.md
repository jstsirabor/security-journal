### What I learned
- A software package is a group of files - typically libraries and other dependencies - that you need for a piece of software to run successfully.
- `apt` means advanced packaging tool and the primary command is `apt-get` which you can use to download, install, update and upgrade software with it
- To check if a package is available e.g. snort, we use the apt search function. `apt-cache search snort`. If it exist, we can use `apt-get install snort`. To remove,  we can use `apt-get remove snort`. However, if we want to remove both the package and the configuration, we can use the `apt-get purge snort`
- Updating updates the list of packages available for download from the repository whereas Upgrade will upgrade the package to the latest version in the repository. To do this, we use `apt-get update` and `apt-get upgrade`. root permission for both is required.
- We can add repositories to get more packages if unavailable by editing the `/etc/apt/sources.list`
- Newer version of Kali no longer have a GUI-based software installation tool however we can download them. The two most common are synaptic or gdebi
- Sometimes the software we want isn't available on any repository perhaps because it's new but it may be available on github - a site that allows developer to share their software with others to download use and provide feedback. For instance, if we download bluediving, a bluetooth hacking and pentesting suite and can't find it in the kali repository, we can install it by cloning it from github using the command `git clone https://www.github.com/balle/bluediving.git` and a new directory will be created for it
