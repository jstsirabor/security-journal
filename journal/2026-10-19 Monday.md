### What I learned
- `if/else1` makes script stop being list of commands and start becoming intelligent.
- The basic `if` structure
	if [ condition ]; then
     do this if the condition is true
	fi

	Three critical rules to remember (Bash is very picky about this):
	1. **Spaces matter.** You must have a space after the `[` and before the `]`. It is `[ condition ]`, not `[condition]`.
	2. **The word `then`** must be there.
	3. **The block ends with `fi`** (which is "if" spelled backwards).

- To check if two strings are exactly the same, we use a single equals sign (`=`).
	if [ "$name" = "root" ]; then
	    echo "You are the superuser."
	fi

- Use the `else` block if we want the script to do something else if the condition isn't met
	if [ condition ]; then
	    # do this if true
	else
	    # do this if false
	fi
- There is no `then` after `else`. The `else` block just runs if the `if` block didn't.

- Use `elif` when you have more than two choices.
	if [ condition1 ]; then
	    # do this if condition1 is true
	elif [ condition2 ]; then
	    # do this if condition1 is false AND condition2 is true
	else
	    # do this if nothing else matched
	fi

- To check if a file exists, we use the -f flag inside the brackets
	if [ -f "/etc/passwd" ]; then
	    echo "The file exists."
	fi

- Here are the most common file checks you will use:

| Flag | What it checks                         |
| ---- | -------------------------------------- |
| `-f` | Is it a **regular file**?              |
| `-d` | Is it a **directory**?                 |
| `-e` | Does it **exist** (file or directory)? |
| `-r` | Is it **readable**?                    |
| `-w` | Is it **writable**?                    |
| `-x` | Is it **executable**?                  |
| `-z` | Is it an empty string?                 |
- The `for` loop makes the computer do the boring, repititive work
	for item in apple banana cherry; do
	    echo "I love $item"
	done
	
	**How it reads:** "For every `item` in this list, run the commands below. When you run out of items, stop."
- The Real Power of `for` loop is Looping over files
	You can use a wildcard (`*`) to loop over every file in a directory:
	for file in *.txt; do
	    echo "Found text file: $file"
	done
- To handle paths, in the `for` loop (`"$target_dir"/*`)
- `exit` is a command that stops the script immediately. It tells the shell, "We are done here, stop running any more lines."
	The number after `exit` (like `1`) is the **exit status**.
		- `exit 0` means "I finished successfully."
		- `exit 1` (or any number from 1 to 255) means "I finished, but an error occurred."
	If the file doesn't exist, we don't want the script to continue and run `wc` or `grep` on a file that isn't there. That would cause a bunch of ugly error messages. `exit 1` stops the script immediately after printing the error, saving the user from confusion. It's a graceful shutdown.
