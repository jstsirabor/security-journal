### What I learned
- `nmap -p-` tells Nmap to scan all 65,535 ports. By default, Nmao scans only the top 1000
- `nmap -A` stands for Agressive. It combines -sV and -sC and OS detection and could take a lot of time to run
- Real penetration testers deal with firewalls blocking their scans every single day. Knowing when to abort a scan and change tactics is a crucial skill
- You need a tool that can open a raw TCP connection and send text. The classic "Swiss Army Knife" for this is **`nc` (Netcat)**. Think of Netcat as a digital telephone. You dial the port, and whatever you type goes directly through the wire.
	- nc localhost 30000
- **NS Record (Name Server)**
	- **What it is:** The authoritative servers for the domain.  
	- **Command:** `dig scanme.nmap.org NS` (Look at the `ANSWER SECTION`).
- **CNAME Record (Canonical Name)**
	- **What it is:** An alias. It points one domain name to another domain name (instead of an IP).  
	- **Command:** `dig www.github.com CNAME` (Notice how GitHub uses a CNAME to route `www` to their main servers).
- `-A` enables OS detection, version detection, default script scanning, and traceroute—not just OS detection. Nmap describes it as intrusive enough to require permission. [Nmap documentation](https://nmap.org/book/man-misc-options.html)
- `tcpwrapped` means the service closed the TCP connection quickly; it is not proof of firewall protection. [Nmap documentation](https://nmap.org/book/vscan-fileformat.html)
- `0.0.0.0:1883` means Mosquitto listens on all local IPv4 interfaces. It may be externally reachable, but firewall, NAT, and cloud/security-group rules still determine actual exposure.
- `ss -tulnp | grep LISTEN` can miss UDP listeners, which often appear as `UNCONN`. Use `sudo ss -tulnp` first, then interpret the full output.
