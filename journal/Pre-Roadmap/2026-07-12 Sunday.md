### What I learned
- You can create a separate user account using the command `sudo adduser labuser`
```
In a line like this:

`-rw-r--r-- 1 darkhand darkhand 4096 Jul 12 14:30 Documents`

- `-rw-r--r--` → permissions 
- `1` → **link count**
- `darkhand` → user owner
- `darkhand` → group owner
- `4096` → file size in bytes
- `Jul 12 14:30` → last modification date

The `1` right after the permissions is the **number of hard links** pointing to that file or directory. For a file, it's usually `1` (just the file itself). For a directory, it's typically at least `2` (the directory itself plus the `.` entry inside it, and more if it has subdirectories).
```
- Dotfiles matter because they often store configurations and credentials 
```
| Directory  | Your security angle                             |
| ---------- | ----------------------------------------------- |
| `/`        | Root compromise = total compromise              |
| `/etc`     | Misconfigurations and weak settings live here   |
| `/home`    | Attackers loot for credentials and keys         |
| `/var/log` | Attack footprints; missing logs = wiped tracks  |
| `/tmp`     | Malware drop zone, writable by everyone         |
| `/usr/bin` | Trojaned binaries and SUID privilege escalation |
| `/bin`     | Critical to boot; if bad, trust nothing         |
```
