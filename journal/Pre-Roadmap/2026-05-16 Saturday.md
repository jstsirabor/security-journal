### What I learned
- `/usr/share/wordlists/metasploit` contains various wordlists that can be used to bruteforce passwords in various password proected devices
- eth0 means first ethernet i.e wired network
- Linux starts counting from 0
- inet is the IP address assigned to that network interface
- Broadcast address is the address used to send out information to all IPs on the internet
- Network mask or netmask is used to determine what part of the IP address is connected to the local network
- lo which is short for loopback address or localhost is a special software address that connects you to your own system. It can be used to test something on the system like personal web server. It is always 127.0.0.1
- wlano is for wireless adapter and displays the MAC address of that device
- `iwconfig` can be used to see information on woreless adapters for wireless hacking such as the adapter's IP address, its MAC address, mode and so on
- The latest standard of wireless communication is `n` while the previous ones were `b` and `g`
- There are different modes for wireless network like managed, monitor or promiscuous. Promiscuous is the mode for crcking wireless passwords
- we can use the ifconfig command to change/spoof our IP address so that attacks appear to come from another source hence escaping IP capture during forensic analysis. We can change netmask, broadcast address and even MAC address. For example: 
```bash
kali >ifconfig eth0 192.168.181.115
kali >ifconfig eth0 192.168.181.115 netmask 255.255.0.0 broadcast 192.168.1.255

```
- MAC address is globally unique and is often used as a security measure to keep hackers out of networks or to trace them hence changing it neutralises those security measures hence it's a good technique for bypassing network access controls. First, we have to take down the interface then enter the ifconfig command followed by the interface name (hw for hardware, ether for ethernet) and the new spoofed MAC address. Finally, we can bring back up the interface for the change to take place
```bash
kali >ifconfig eth0 down
kali >ifconfig eth0 hw ether 00:11:22:33:44:55
kali >ifconfig eth0 up
```
- We can also use the Dynamic Host Configuration Protocol (DHCP) to assign new IP addresses. It runs in the bakcgrounf and assigns IP addresses to all the systems on the subnet and keep log files of which IP address is allocated to which machine at any one time which could help forensic analysts. To request IP address from DHCP, simply call the DHCP server withe command dhclient along with the interface we want the IP assigned to
```bash
kali >dhclient eth0 
# This works for debian as kali isbuilt on it
# This would assign a new IP address, a new broadcast address and a new netmask for the network interface
```
- DNS  (Domain Name System) is a critical component of the internet and although it's used to translate domain names to IP addresses, a hacker can use it to gather information on the target
- We can use the `dig` command to reveal information about DNS of a target domain. We can also use it to get information on email servers connected to a domain by adding the `mx` option. This is critical for email systems
```bash
kali >dig hackers-arise.com ns
# ns is short for nameserver ans get information on a domain nameserver
kali >dig hackers-arise.com mx
# mx 
```
